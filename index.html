🚨 P1 Critical Runbooks (Truy cập nhanh)

    ❓ Câu Hỏi Thường Gặp (IT FAQ)

    1. Làm sao để xin cấp quyền VPN / SSH vào môi trường Production?
    Tạo yêu cầu trên cổng ITSM kèm phê duyệt của Engineering Manager. Quyền truy cập Production được cấp theo cơ chế Just-In-Time (tối đa 4 giờ) qua nhóm AD SG-Prod-Bastion-JIT.
    2. Quy tắc bảo mật khi viết bài lên trang IT Knowledge Hub?
    Tuyệt đối KHÔNG dán mật khẩu, Private Key, Connection String hoặc Bearer Token thật vào bài viết. Hệ thống có bộ lọc tự động chặn các chuỗi chứa khóa bí mật (Zero Secret Leakage).
    3. Bao lâu cần rà soát (Review) lại một bài Runbook?
    Mọi Runbook mức P1/P2 phải được kiểm chứng định kỳ mỗi 90–180 ngày hoặc ngay sau mỗi đợt nâng cấp hạ tầng. Các bài quá hạn sẽ tự động chuyển sang nhãn Needs Review.
    4. Làm sao để sao lưu hoặc chia sẻ trang Knowledge Base này cho đồng nghiệp?
    Nhấn nút ⬇️ Xuất JSON trên thanh công cụ để tải toàn bộ cơ sở dữ liệu bài viết về máy, hoặc chạy Start-KBServer.ps1 để chia sẻ qua mạng nội bộ LAN.

    🔐 Phân Quyền Truy Cập (RBAC) & Đồng Bộ GitHub Cloud

    Xác thực quyền trực tiếp từ GitHub Repository API (permissions.admin / push / pull) và lưu trữ đám mây

    1. Bảng Ma Trận Phân Quyền (Role-Based Access Control Matrix)

    Vai trò (Role) Ánh xạ quyền trên GitHub Repo Quyền trên trang IT Knowledge Hub
    👑 Admin permissions.admin = true (Owner / Maintain) Toàn quyền: Xem, Tạo mới, Chỉnh sửa, Xóa bài, Nhập/Xuất JSON, Commit lên GitHub
    ✏️ Editor permissions.push = true (Write Collaborator) Đóng góp: Xem, Tạo mới, Chỉnh sửa bài viết & Commit lên GitHub (Khóa quyền Xóa bài)
    👁️ Viewer permissions.pull = true (Read-Only Member) Chỉ đọc: Tìm kiếm, Xem bài viết, Copy CLI & Markdown (Khóa Tạo/Sửa/Xóa/Import)

    2. Chuyển Đổi Nhanh Vai Trò (Kiểm thử RBAC Local / Offline)

    Chế độ: Local / Chưa gắn Token GitHub

    3. Kết Nối GitHub Private Repository (Lưu Trữ & Xác Thực Thực Tế)

    💡 Bảo mật Tier 1: Token của bạn chỉ giữ trong bộ nhớ phiên trình duyệt (sessionStorage) để gọi trực tiếp tới https://api.github.com.
