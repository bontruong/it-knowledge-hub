🚨 Tài Liệu Trọng Yếu (P1 Critical)

    💡 Hướng Dẫn Bàn Giao & Ghi Chép Trực Tiếp

    1. Người bàn giao ghi chép trực tiếp vào hệ thống như thế nào?
    Chọn đúng hạng mục cần bàn giao trong danh sách, bấm ✏️ Chỉnh sửa bài viết để người bàn giao trực tiếp gõ thông tin, hướng dẫn thực tế, tài khoản, cấu hình và checklist mà không cần soạn thảo thủ công bên ngoài.
    2. Làm thế nào để upload các file tài liệu và biểu mẫu bàn giao?
    Bấm vào bài viết bất kỳ, kéo thả file (PDF, Word, Excel, ZIP...) vào khung 📁 Tài Liệu Bàn Giao Đính Kèm hoặc mở 📁 Kho Tài Liệu trên thanh điều hướng để xem và tải về tất cả tài liệu đã nhận.
    3. Quyền của tài khoản Editor trong các buổi bàn giao là gì?
    Tài khoản có quyền Editor có thể tạo bài viết mới, chỉnh sửa nội dung bài viết và tải tài liệu lên trực tiếp trên website. Toàn bộ các thao tác can thiệp mã nguồn GitHub, Xuất/Nhập JSON được bảo vệ và ẩn hoàn toàn.

    👥 Quản Lý Tài Khoản Người Dùng & Phân Quyền (User Management)

    Tạo tài khoản mới, gán quyền Admin / Editor / Viewer, chuyển đổi người dùng đăng nhập và mời vào GitHub Repo

    1. ➕ Tạo Tài Khoản Người Dùng Mới (Chỉ dành cho Admin)

    2. 📋 Danh Sách Tài Khoản Hệ Thống (Bấm "Đăng nhập" để chuyển tài khoản)

    💡 Mật khẩu mặc định của các tài khoản khởi tạo sẵn bên dưới là NDS@2026 (đã được băm SHA-256 an toàn).

    Họ và tên Email / Username Phòng ban Vai trò (Role) GitHub Trạng thái Thao tác

    🔐 Đồng Bộ Đám Mây GitHub & Ma Trận Phân Quyền

    Xác thực quyền trực tiếp từ GitHub Repository API (permissions.admin / push / pull) và lưu trữ đám mây

    1. Bảng Ma Trận Phân Quyền (Role-Based Access Control Matrix)

    Vai trò (Role) Ánh xạ quyền trên GitHub Repo Quyền trên trang NDS IT Knowledge Hub
    👑 Admin permissions.admin = true (Owner / Maintain) Toàn quyền: Xem, Tạo mới, Chỉnh sửa, Xóa bài, Quản lý User, Commit GitHub, Xuất & Nhập JSON
    ✏️ Editor Chỉ cấp quyền trên Website Chỉ xử lý trên Website: Xem, Tạo mới, Chỉnh sửa bài viết, Upload tài liệu (Không can thiệp GitHub, Ẩn Xuất/Nhập JSON, Khóa Xóa bài & Quản lý User)
    👁️ Viewer permissions.pull = true (Read-Only) Chỉ đọc: Tìm kiếm, Xem bài viết, Tải tài liệu đính kèm (Khóa Tạo/Sửa/Xóa/Upload & Ẩn GitHub/JSON)

    2. Chuyển Đổi Nhanh Vai Trò (Kiểm thử RBAC Nhanh)

    Chế độ: Tài khoản nội bộ / GitHub Sync

    3. Kết Nối GitHub Repository (bontruong/it-knowledge-hub)
